# Example requests

## App launcher
Design a square launcher icon for FlowTick, a calm productivity app. Explore three distinct concepts, then create the recommended concept as polished PNG and a simplified vector companion. Use blue/cyan, no lettering, and verify the silhouette at small sizes.

## UI family
Create 16 outline icons for a SaaS dashboard: home, analytics, reports, users, billing, settings, notifications, help, search, filter, export, upload, download, refresh, calendar and integrations. Use a 24px grid and real SVG markup. Lock consistent stroke and optical weight.

## Feature icons
Create six isometric feature icons for onboarding, analytics, cloud sync, collaboration, AI suggestions and automation. Establish one anchor and reuse its perspective, palette and lighting. Deliver individual PNGs and simplified SVG companions.

## Brand symbol
Design an original mark for PortLink, a logistics technology product connecting shippers, warehouses and customs. Explore routes, nodes and flow without generic ship clichés. Establish monochrome vector geometry first, then generate a colored PNG variant.
