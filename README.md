# Icon Design Skill

A reusable, style-adaptive icon design workflow for Gemini and AI agents. Covers app icons, UI icon systems, brand symbols, feature illustrations and icon packs.

## Quick start
- **Gemini:** upload `GEMINI.md` as Gem knowledge or paste it into the conversation.
- **Agent/skill runtime:** use `SKILL.md` as the entry point.
- Read `references/catalog.md` and relevant templates when available.

## Principles
- Mixed style means adaptive style selection, not inconsistent icons within one family.
- Generate raster artwork with Gemini image generation when available.
- Author real, editable SVG geometry separately; never wrap a bitmap in SVG.
- State clearly which files were generated, rendered, validated or not tested.

## Structure
See `SKILL.md` for the workflow, `GEMINI.md` for the standalone Gemini instructions, `references/` for references, `templates/` for production checklists and `examples/` for sample briefs.
